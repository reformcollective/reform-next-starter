# Basic tier verification: TikTok, Twitch, Spotify

Date of checks: 2026-10-27. All "live" checks were curl fetches from this machine (no browser, so no runtime playback was exercised). Raw fetches are in /private/tmp/claude-501/w/ (tt/, twj/, sp_*.js, *.txt).

Legend for "verified how":

- DOC = quote or table from an official docs page I fetched.
- SRC = read in the live provider script/page I downloaded (so it is what ships today, even if undocumented).
- ELEM = read in the local media-element package source (node_modules/.pnpm/<pkg>/...).
- CURL = live request/response.
- NOT VERIFIED = could not check (needs a real browser or auth).

Packages inspected: twitch-video-element 0.1.6, tiktok-video-element 0.1.2, spotify-audio-element 1.0.4 (all in node_modules/.pnpm).

### 1e. What tiktok-video-element 0.1.2 adds or fails to expose (ELEM)

- Builds `https://www.tiktok.com/player/v1/{id}` and passes `controls, autoplay, muted, loop, rel=0` (+ any `config` keys, so extra params like `progress_bar`, `closed_caption` can be passed through `config`).
- Maps: play, pause, seek (`currentTime=`), muted (`mute`/`unMute`), `paused`, `duration`, `currentTime`, `volume` getter (0..1).
- Events dispatched: emptied, pause, ended, play, waiting, durationchange, timeupdate, volumechange, error. NOT dispatched: loadedmetadata, canplay, playing, seeking, seeked, loadstart (no `playing` event even though state 1 exists; it fires `play`).
- Gaps: volume setter is a warning no-op (although the live player has an undocumented `setVolume`); `onPlayerError` is ignored (falls to `default: console.warn("Unhandled TikTok player message:")`, so `onPlayerError` and `onImageChange` log a warning); `onPlayerReady` only resolves a promise, it dispatches no event; `loop` attribute change reloads the iframe; `src` regex requires `tiktok.com/(player/v1/|share/video/|@user/video/)<digits>` so short links fail (`srcId` becomes null and URL becomes `.../player/v1/null`); `ended` property absent; no `readyState`; no poster.

### 1f. Recommended basic-tier feature set for TikTok

play, pause, seek, mute/unmute, state events (ready, play, pause, waiting, ended, error), timeupdate + duration (push), volumechange event, controls and other chrome flags via URL, autoplay (muted), loop via URL param. Optional/undocumented: setVolume (flag as unsupported-by-contract). Not possible: quality, captions toggle, fullscreen API, start time, poster/title from oEmbed.

### 2e. What twitch-video-element 0.1.6 adds or fails to expose (ELEM)

- Accepts `twitch.tv/videos/<id>`, `twitch.tv/?video=<id>`, `twitch.tv/<channel>` URLs. Builds `https://player.twitch.tv/?video=v<id>` or `?channel=`, with `parent=location.hostname`, `controls` (false unless attribute), `autoplay` (false unless attribute), `muted`, `preload`, plus `config`. Does NOT pass `time`/`t`, `volume`, `quality` (only via `config`). Does NOT support collections or clips (no regex), and `loop` attribute is a no-op on playback.
- Implements postMessage directly (does not load v1.js): play, pause, seek, set muted, set volume, `currentTime` get/set, `duration` (NaN until state arrives), `paused`, `ended`, `volume`, `muted`, `buffered` (bufferSize seconds), `getVideoPlaybackQuality()` (throws if no state yet because it reads `#playerState.stats.videoStats` with no guard).
- Events dispatched: emptied, loadstart, loadedmetadata (on ready), seeking/seeked (on SEEK then PLAYING), playing, pause, play, ended, plus passthrough of any `twitch-embed` eventName (so `playbackBlocked`, `offline`, `online`, `captions`, `error` surface as plain Events WITHOUT their payload), durationchange, timeupdate, volumechange, progress.
- Gaps: no `setQuality`/`getQualities`, no captions API, no `setChannel` or collection switching, `readyState` only 0, 1, 3; `:host(:not([controls])){pointer-events:none}` so without `controls` the iframe cannot be clicked; message handler `await new Promise(setTimeout 10ms)` per message; `paused` before first state is `!autoplay`. `volume` is 0..1 same as Twitch.

### 2f. Recommended basic-tier feature set for Twitch

URL: channel / video / collection / clip, `parent` (auto from `location.hostname`), `autoplay`, `muted`, `time` (VOD), `controls` (undocumented, SRC-verified). JS (via postMessage or Twitch.Player): play, pause, seek (VOD), mute, volume, getDuration/getCurrentTime (VOD), ended, captions on/off, quality list/set, events ready, play, pause, playing, seek, ended, offline, online, playbackBlocked, captions. No loop, no playback rate, no programmatic fullscreen. Clips: no JS API at all (iframe only, `autoplay`, `muted`, `preload`). Poster/title/duration need Helix and a token (NOT VERIFIED).

### 3d. What spotify-audio-element 1.0.4 adds or fails to expose (ELEM)

- Wraps the iFrame API, loads `https://open.spotify.com/embed-podcast/iframe-api/v1` itself. Config via `el.config = {startAt, theme:'dark', preferVideo}` (no attribute for these).
- Maps: play, pause, `currentTime` get/set (seek, note setter takes the old value back until the next update), `duration` (NaN until first update, seconds), `paused`, `loop`, `src`.
- Events dispatched: emptied, loadstart, loadedmetadata, durationchange, volumechange (fired once on ready only), timeupdate, play, pause, waiting, playing, ended.
- Faked / gaps: `ended` is synthesized when `ceil(currentTime) >= duration` and not seeking; `loop` is emulated by `currentTime = 1` (not 0); there is a `this.continuous` flag referenced but never defined. `muted` always returns false and ignores set; `volume` always 1 and ignores set (no-ops, no warnings). `ended` getter is true whenever `ceil(currentTime) >= duration`, which is also true when both are 0. `:host(:not([controls])){display:none !important}` hides the iframe when `controls` attribute is absent (audio-only usage would break playback in some browsers, NOT VERIFIED). No fullscreen, no `restart`, `togglePlay`, `loadEntity`, `error` forwarding, no `onFullscreen*` hooks. The `loop` attribute is not in the `MATCH_SRC` URL building. Only `open.spotify.com/{type}/{id}` URLs match (no `spotify:` URIs, no `spotify.link`).

### 3e. Recommended basic-tier feature set for Spotify

play, pause/resume/toggle, restart, seek, load another entity, startAt, theme dark, preferVideo, events ready, playback_started, playback_update (position/duration in ms, isPaused, isBuffering). Derived: timeupdate, durationchange, play/pause/waiting/playing/ended (ended is inferred). Not possible: volume, mute, loop (emulate), captions, quality, programmatic fullscreen. Poster and title from oEmbed (300x300 cover); duration only after the iframe reports it (or scrape the embed page).
